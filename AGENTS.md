# AGENTS.md — Машинно-читаемый контекст и операционный регламент проекта

## 1. Миссия, KPI и границы проекта (Mission & Scope)

### 1.1. Миссия
Создать высококачественную, автономную интерактивную электронную книгу-симулятор по фундаментальным основам компьютерных сетей (стандарты сетевой инженерии), адаптированную для подростков 13 лет. Объяснение строится через тактильные визуализации, интерактивные мини-лаборатории в каждом подразделе и геймифицированную практику.

### 1.2. KPI проекта
- **Автономность 100%:** Работа прямо в браузере без сборщиков и внешних зависимостей (открытие `index.html` локально).
- **Интерактивная плотность:** Минимум 1 живой интерактивный виджет на каждый концепт/главу.
- **Детская эргономика (13 лет):** Понятные аналогии из игр и реальной жизни, обратная связь в реальном времени, звуковые эффекты на чистом Web Audio API, квизы с мгновенной проверкой.
- **Тестовое покрытие ядра (Core Engine):** 100% модульное покрытие сетевой математики, симулятора CAM-таблицы, алгоритмов маршрутизации и валидации пакетов.

### 1.3. Границы проекта (Scope & Non-Goals)
- **In-Scope:**
  - 8 тематических частей, охватывающих все ключевые разделы сетей (Layer 1–4, сетевые сервисы, основы безопасности, Wi-Fi).
  - Интерактивные мини-тренажеры (8-битный тумблер, матрешка инкапсуляции, обучение свича, нарезка подсетей, OSPF-навигатор, симулятор TCP-рукопожатия, ARP/DHCP/DNS/NAT).
  - Встроенная песочница «Packet Tracer Lite» прямо в браузере.
  - Сохранение прогресса в `localStorage`.
- **Non-Goals:**
  - Использование тяжелых сторонних фреймворков (React, Angular, Vue, Webpack, Vite). Используется чистый Vanilla JS (ES Modules) и современные Web Standards.
  - Использование внешних аудиофайлов mp3/wav (все звуки синтезируются в реальном времени через `Web Audio API`).

## 3. Архитектурные правила и инварианты

1. **Engine-First Архитектура:**
   Логика виртуальной сети (`js/engine/`) строго отделена от DOM/UI (`js/widgets/`). Движок работает с моделями пакетов, таблицами коммутации и маршрутизации независимо от отображения.
2. **Нулевой оверхед зависимостей:**
   Все алгоритмы (Dijkstra для OSPF, побитовые маски, расчет CRC/контрольных сумм, генерация звуков) пишутся на нативном JavaScript.
3. **Строгая доступность и темизация:**
   Поддержка темной и светлой темы через `:root { color-scheme: light dark; }`, CSS `light-dark()` токены и превенцию FOUC в `<head>`.

## 4. Подводные камни и нетривиальные решения

1. **Побитовые операции в JavaScript (Bitwise 32-bit signed):**
   В JS побитовые операции (`<<`, `>>`, `|`, `&`) приводят операнды к 32-битным знаковым целым. При сдвиге старшего бита (например, маска `128.0.0.0`) число становится отрицательным.
   *Решение:* Использование беззнакового сдвига вправо `>>> 0` для нормализации IP-адресов к беззнаковому `uint32`.
2. **Синтез аудио без ассетов:**
   Вместо загрузки внешних аудиофайлов используется `AudioContext` с осцилляторами (`sine`, `triangle`, `square`) и огибающими громкости (`gainNode.gain.exponentialRampToValueAtTime`). Это гарантирует мгновенный звук оффлайн без CORS-ошибок.
